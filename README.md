# ATPL(H) Tools

ATPL(H) study tools are stored under `tools/`, grouped by subject:

- `tools/general/`: General calculator
- `tools/gnav/flight-planning/`: ICAO flight-plan interactive guide
- `tools/rnav/`: Radionavigation aids
- `tools/agk/engines/`: AGK engine tools
- `tools/agk/instruments/`: AGK instrument tools
- `tools/agk/electrics/`: Three-phase induction motor
- `tools/meteo/`: Front simulator
- `tools/comms/`: Communications tools
- `tools/principles-of-flight/`: Hinge Offset Explainer

The homepage links to the tools in their subject folders. Add future tools to the matching folder as they become available.

The homepage also includes curated study and safety references. External links are independent resources; use current official aeronautical information for flight planning and operations.
