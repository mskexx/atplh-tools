# ATPL(H) Tools

ATPL(H) study tools are stored under `tools/`, grouped by subject:

- `tools/general/`: General calculator
- `tools/flight-planning/`: ICAO flight-plan interactive guide
- `tools/rnav/`: Radionavigation aids
- `tools/agk/electrics/`: Three-phase induction motor and logic gates
- `tools/agk/systems/`: Helicopter system map
- `tools/meteo/`: Front simulator
- `tools/principles-of-flight/`: Hinge Offset Explainer

`tools/home-link.js` provides a shared helicopter-logo link back to the homepage on each tool page.

The homepage links to the available tools in their subject folders. Add future tools to the matching folder as they become available.

The homepage also includes curated study and safety references. External links are independent resources; use current official aeronautical information for flight planning and operations.
